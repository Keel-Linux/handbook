# Evidence: real-node test of keel 0.23.105 and confconsole 2.2.3+keel27, the access network (0098), the certificate after the fence and the fence rule

Date: 2026-11-25. Sites: the BR1 test VM and the BR2 test VM (nested
Proxmox VE).
Status: draft. For decision 0098 (proposed, handbook PR 218), keel pull
requests 321, 323, 324 and 325, and confconsole pull request 45.

## Question

keel 0.23.105 and confconsole 2.2.3+keel27 are in the APT suite
`trixie-testing` (apt PR 128). They say:

- keel#321: `tls.acme` waits while the init fence is up; when the fence
  stops for good, `keel-certificate.service` requests the certificate.
- keel#323: when the fence stops, `keel firewall refresh` (drop-in)
  writes and loads keel's ruleset again without the fence rule.
- keel#324 and #325 (decision 0098): the access network `keel-access`
  (UDP 51822), `keel access invite/list/remove/invites/cancel`, the
  enrolment by one pasted command with `curl --pinnedpubkey`, a firewall
  in which an access peer reaches only SSH, the database relay (and the
  `access` ports) on the access address; IPv4 SSH closed by an attended
  apply where the node has global IPv6 and sshd on IPv6;
  `keel-firewall-ssh-guard` opens IPv4 22 again when IPv6 is lost and
  removes its rule when IPv6 is back.
- confconsole#45: webroot issuance with nginx kept running; a refusal
  (exit 75) while the fence is up.

The method follows the 0097 real tests (handbook PRs 200 to 217). A
failure is a result. No code was changed. Each statement was tested by
action unless it says "read from the code".

answers only an AAAA record). No production DNS was used. Before the
first boot, `/etc/dehydrated/confconsole.config` was made as a copy of
confconsole's default with `CA="letsencrypt-test"` added. The account
directory under `/var/lib/dehydrated/accounts/` is the base64 of the
staging directory URL, and each certificate's issuer is `(STAGING)
Baloney Bulgur YE2`. Port 80 of the BR1 test bridge answers the staging
validators over IPv6.

presses Enter (the default answer) each time the screen is still for

from the secret files (not printed). A first try with `script` and a
