# Advisories

An advisory tells users of a defect in a package or layer that Keel
Linux published, who is affected, what to do, and when the fix comes.
One file for each advisory, named `DATE-SUBJECT.md`. A withdrawal from
`trixie` (`bin/withdraw` in the apt repository) always has an advisory.
